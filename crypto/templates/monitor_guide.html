📚 监控台操作手册

MACD & ADX Pro3 策略监控台（首页 /）全部按钮与功能模块的分页说明。每页聚焦一个模块，支持顶栏直达与打印导出。

导出 PDF：打印对话框选「另存为 PDF」；打印时自动展开全部章节

页面结构

监控台自上而下分为四区：① 监控币种选择面板（标签墙 + 高级筛选 + 币种管理按钮）；② 行情卡片区（选中币种的实时策略数据，含查看详情/多周期总览入口）；③ 刷新控制区（手动刷新 + 自动刷新间隔）；④ 批量多周期趋势分析面板（全币种库 15m/1H/4H/1D 四周期指标表格）。

典型工作流

  1. 点「🚀 批量更新趋势数据」刷新全币种库指标（约 1~3 分钟，含新增币种）；
  2. 用高级筛选（趋势/ADX/ATR/ER）圈出「趋势强且波动大」的候选币；
  3. 勾选候选币 → 点「保存选择」，卡片区开始实时监控这些币种；
  4. 需要临时观察趋势扫描页发现的币 → 添加为浮动币种，满意后「⬆ 提升为固定」；
  5. 市值排名变化后 → 到交易配置页点「🔄 更新市值列表」重建市值 Top50 池。

固定池 / 浮动池 / 宇宙 三个概念

固定币种=市值 Top50 稳定监控池（config 的 all_coins，按市值降序展示）；浮动币种=从趋势扫描页临时加入的观察对象；币种库(宇宙)=crypto_coins 表/CSV，是批量趋势分析的输入清单。移除固定币会同步删宇宙，提升为固定会同步写宇宙，三者始终保持一致。
☑全选所有
功能
选中币种墙上的全部币种（固定+浮动）。
场景
需要盯全池时一键勾满。
注意
币种多时卡片刷新变慢，建议优先用筛选后再批量选。
✖重置选择
功能
取消所有「选中(激活)」标签，不动星标/固定属性。
场景
快速清空当前监控卡片列表。
★全选星标 / ☆ 重置星标
功能
把所有已星标币设为选中 / 清除全部星标。
场景
星标=你的重点观察清单，每天开盘一键召回。
🔄同步（CSV）
功能
把币种库中的币合并进可用列表（保留手动添加项）。
场景
币种库有更新、页面还没反映时。
➖移除选中
功能
把选中的固定币种移出监控池，并同步从币种库(DB+CSV)删除。
场景
清理已下架/失去关注度的币。
注意
不可恢复（除非重新提升/入库）；至少保留 1 个固定币；「CSV同步固定」不会让被移除的币复活。
⬆提升为固定
功能
把选中的浮动币种转为固定币，同时写入币种库。
场景
趋势扫描发现好币，先浮动观察、确认后转正。
注意
新转正币的指标列为空，需再跑一次批量更新。
📥CSV同步固定
功能
以币种库为准整体覆盖固定列表（库序），浮动池不受影响。
场景
固定列表与币种库出现漂移时对齐。
🗑️清空浮动币种
功能
一次性移除全部浮动观察币（固定池不动）。
场景
复盘结束、清场。
保存选择
功能
把当前「选中」的币种集合持久化为默认监控列表（default_selected）。
场景
筛选组合满意后固化，下次开页即恢复。
注意
只能保存可用列表内的币；全部无效时自动回退前 3 个。
🔄手动刷新数据
功能
立即重算所有选中币种的策略数据并刷新卡片。
场景
行情剧烈波动时按把刷新。
⏱自动刷新间隔 + 应用
功能
设置轮询周期（分钟，0=关闭），点「应用」生效。

每次刷新会实调 OKX 行情接口，间隔过小会触发限频。

功能

功能

🗂周期选择器（bar-selector）
功能

注意

面板定位

对币种库（宇宙）全量币逐周期跑 Pro3 策略，产出趋势方向、交易价、盈亏%、MACD/DIF/ADX/ATR%/SAR/ER 指标表。核心列（趋势/交易价/盈亏%/MACD）常显；指标列（DIF/ADX/ATR/SAR/ER/时间）可通过开关整体显隐，默认全部展开。ER 为 Kaufman 效率系数（0~1，越大越单边），与 ADX（趋势强度）、ATR%（10 倍杠杆口径波动）搭配可筛「趋势强且波动大」。
🚀批量更新趋势数据
功能
后台并发扫描全宇宙（15m/1H/4H/1D），进度条实时更新，结果双写 DB+CSV。
场景
每天开工先跑一轮；新增币种后必跑（否则指标为空）。
注意
55 币约 1~3 分钟；期间避免重复点击，OKX 限频时个别币可能留空，再跑一轮补齐。

两套筛选，各管各的对象

① 币种墙高级筛选（面板顶部「🔽 筛选」展开）：作用于币种标签墙，不匹配的标签变暗，用于圈选监控对象；② 批量面板筛选区：作用于趋势表格行，用于分析视角过滤。两者互不影响。
🔽筛选（展开/收起）
功能
展开币种墙高级筛选面板：趋势(1H/4H/1D↑↓)、组合(4H+1D双涨/双跌)、盈亏(各周期盈/亏)、指标阈值(ADX/ATR%>)、排序下拉。
注意
条件基于最近一轮批量分析结果；未跑过批量更新时无数据可筛。
🔍应用筛选 / ✖ 清除
功能
按当前条件过滤标签墙（指标类为 AND 关系），或还原。「默认(市值)」排序即按固定池市值降序原序。
⭐批量星标
功能
把筛选命中的全部币种一次加星标。
场景
「4H↑+1D↑ & ADX_4H>25 & ATR_4H%>20」一轮圈住强趋势币。
🧮指标阈值默认值
功能
ADX>25、ATR_1H%>10 / ATR_4H%>20 / ATR_1D%>30（ATR% 为 10 倍杠杆口径，非裸波动）。
注意
清空输入框=该条件不参与筛选。
📉表格筛选区（周期趋势/MACD/ADX）
功能
批量面板内按趋势、MACD 柱区间、ADX 区间过滤表格行，「应用筛选/清除筛选」控制。

浮动币种从哪来

顶栏「🚀 趋势扫描」页对全市场做涨幅/跌幅/成交额三大榜与趋势扫描，看中的币可「添加监控」——即加入浮动池（标签墙橙色区分）。浮动币参与卡片监控与筛选，但不属于稳定池；转正走「⬆ 提升为固定」，放弃用行内 ✖ 或「🗑️ 清空浮动币种」。

与批量分析的关系

批量趋势分析的输入是币种库（宇宙），不是固定池：提升为固定会同时入宇宙，所以新币立刻可被批量分析覆盖；仅加浮动的币若不在宇宙中，表格无其行，需先「⬆ 提升为固定」或手动入库。

市值 Top50 池的维护入口（位于 ⏰定时任务 → 交易配置 Tab）

固定池应始终覆盖当前市值前 50 的热门币。入口在交易配置页「币种与周期配置」区块右上角。
🪙 打开 Top50 币种导览页（实时行情+简介） ⏰ 去交易配置页维护池子
🔄更新市值列表（交易配置页）
功能
拉取 CoinGecko 实时市值榜 → 剔除稳定币/包装资产 → 校验 OKX USDT 线性永续 → 取前 50 整体替换固定池，并同步 config(DB+文件) 与币种库宇宙；记录每币市值排名供全站排序。
场景
市值榜变化明显后（约每周一次）重建池子。
注意
① 外网不可达时直接失败、零改动（不会写坏配置）；② 浮动池不受影响；③ 替换后到监控台点一次「🚀 批量更新趋势数据」补齐新币指标。
💰固定币种详情面板（交易配置页）
功能
表格展示每个固定币的市值排名/价格/24H涨跌/成交额/流通市值/流动性(成交额÷市值)，右上角「🔄 刷新数据」强制重拉 CoinGecko（平时 120 秒缓存）。
场景
开单前核对池内标的流动性与市场热度。
注意
未进市值榜前 100 的手动提升币显示「未入榜」，属正常。
⬇命令行版（等效入口）
功能
python data/update_fixed_coins_top50.py（加 --dry-run 只预演），与页面按钮共用同一模块 market_cap_updater，口径完全一致。
🔢市值降序展示规则
功能
监控台标签墙、详情页下拉、分析记录筛选等所有固定币展示位统一按市值排名降序（后端排序，前端同源）。
注意
手动提升入池的币暂无市值排名，排在池尾；下次「更新市值列表」或跑过详情接口后归位。交易配置的币种列表顺序是调度执行顺序（可拖拽），不受市值排序影响。
