# 热量缺口功能模块说明

## 1. 模块简介

**热量缺口管理**是监控台中的健康管理辅助模块：通过记录每日体重、饮食摄入、运动步数，自动计算热量缺口，帮助用户科学管理体脂。同时建立食物热量库，方便快速录入与累积热量数据。

### 1.1 核心目标

- 量化每日热量收支，跟踪热量缺口累积
- 建立个人食物热量库，减少重复录入
- 通过长期数据观察体重变化趋势与热量缺口的关系

### 1.2 设计理念

- **数据驱动**：用数字量化每日饮食与运动，减少主观猜测
- **渐进积累**：每餐录入的食物自动汇入食物热量库，越用越方便
- **反馈闭环**：每日热量缺口 → 累积进度 → 体重变化，形成完整反馈链

## 2. 功能总览

| 功能 | 说明 |
|------|------|
| 每日记录 | 填写日期、早晚体重、三餐食物与热量、步数，自动计算各项指标 |
| 随笔入口 | 减肥心得/所思所想统一记录在独立的『随笔复盘』模块：每日记录表单下方入口随手跳转，历史行可针对某日补记；随笔通过 `linked_from='calorie:日期'` 关联当日热量记录，双向跳转 |
| 食物热量库 | 输入时实时搜索，选中候选项自动回填食物名与热量，支持多食物添加；新食物自动加入库中 |
| 食物库管理 | 浏览/搜索/编辑/删除食物热量库中的条目 |
| 统计看板 | 总热量缺口、当前累积缺口、当前进度、平均值统计 |
| 历史记录 | 查看日历/列表形式的历史记录，支持编辑与删除 |

## 3. 字段与公式

### 3.1 每日记录字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | date | 记录日期，格式 YYYY-MM-DD |
| 早上称重 | float | 晨起空腹体重（kg） |
| 晚上称重 | float | 睡前体重（kg） |
| 基础代谢 | float | **自动计算**，见下文公式 |
| 早饭食物 | string | 早餐食物名称 |
| 早饭摄入 | float | 早餐总热量（kcal） |
| 午饭食物 | string | 午餐食物名称 |
| 午饭摄入 | float | 午餐总热量（kcal） |
| 晚饭食物 | string | 晚餐食物名称 |
| 晚饭摄入 | float | 晚餐总热量（kcal） |
| 摄入缺口 | float | **自动计算**，基础代谢 - 三餐总摄入 |
| 当日步数 | int | 每日步数 |
| 运动消耗 | float | **自动计算**，见下文公式 |
| 热量缺口 | float | **自动计算**，摄入缺口 + 运动消耗 |

### 3.2 计算公式

#### 基础代谢（BMR）

使用 Mifflin-St Jeor 公式（男性版）：

```
基础代谢 = (10 × 早上称重 / 2) + (6.25 × 身高) - (5 × 29) + 5
```

其中：
- 身高 = 169 cm（固定值，可配置）
- 年龄 = 30（固定值，可配置）

#### 摄入缺口

```
摄入缺口 = 基础代谢 - (早饭摄入 + 午饭摄入 + 晚饭摄入)
```

#### 运动消耗

```
运动消耗 = 当日步数 × 0.7 × 55 / 1000
```

其中：
- 0.7 = 步频系数（步/分钟）
- 55 = 体重系数（kg，固定值，可配置）
- 1000 = 单位换算（米→公里）

#### 热量缺口

```
热量缺口 = 摄入缺口 + 运动消耗
```

> 热量缺口为正值表示消耗 > 摄入（适合减脂），负值表示摄入 > 消耗（适合增重）

### 3.3 统计指标

| 指标 | 公式 |
|------|------|
| 总热量缺口 | 所有记录的热量缺口之和 |
| 当前累积热量缺口 | 最近一条记录的累积热量缺口（含历史累计） |
| 当前进度 | 当前累积热量缺口 ÷ 总目标缺口（默认 100000 kcal，约等于 13kg 脂肪） |
| 平均热量缺口 | 总热量缺口 ÷ 记录天数 |
| 平均摄入 | 三餐总摄入之和 ÷ 记录天数 |
| 平均摄入缺口 | 摄入缺口之和 ÷ 记录天数 |
| 平均步数 | 当日步数之和 ÷ 记录天数 |
| 平均运动消耗 | 运动消耗之和 ÷ 记录天数 |

> 1kg 体脂 ≈ 7700 kcal，减脂 10kg 目标缺口约 77000 kcal

## 4. 食物热量库

### 4.1 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| name | string | 食物名称 |
| unit | string | 计量单位：100克 / 10克 / 1个 / 1份 |
| calories | float | 对应单位的热量（kcal） |
| category | string | 分类（可选）：主食/肉蛋/蔬菜/水果/乳制品/零食/饮品/其他 |
| created_at | string | 创建时间 |

### 4.2 使用规则

1. **记录三餐时**：在食物名称输入框中搜索，从下拉列表中选择已有食物，自动填入热量
2. **自动载入**：如果输入的食物名称在库中不存在，提交记录时自动新增到食物热量库
3. **手动管理**：支持查看全部食物库、编辑热量值、删除条目
4. **去重**：食物名称不区分大小写，相同名称自动复用已有条目

### 5.3 每日使用流程

1. 早上起床称重 → 填入"早上称重"
2. 每餐吃饭时：搜索食物名称 → 选中自动填入热量，或手动输入热量
3. 睡前称重 → 填入"晚上称重"
4. 记录当日步数（从手机/手环获取）
5. 点击保存，系统自动计算所有指标

## 7. 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `身高` | 175 cm | 基础代谢公式中的身高参数 |
| `年龄` | 29 | 基础代谢公式中的年龄参数 |
| `步频系数` | 0.7 | 运动消耗公式中的步频系数 |
| `体重系数` | 55 kg | 运动消耗公式中的体重系数 |
| `总目标缺口` | 100000 kcal | 进度计算的目标值（约 13kg 脂肪） |

配置参数可在 `calorie_routes.py` 顶部的 `CONFIG` 字典中修改。
