# 海龟交易策略完整逻辑(高杠杆合约改造版)

> 原版:Richard Dennis / William Eckhardt,1983 年"海龟实验",交易美国商品期货。
> 本文档分两部分:**第一部分**完整还原经典海龟规则;**第二部分**针对加密货币高杠杆永续合约环境(10x~20x)逐条改造。
> 核心思想一句话:**海龟从不预测趋势,只用突破跟随趋势;它的生命线不是入场信号,而是 N 值仓位控制 + 2N 硬止损。**

---

## 第一部分:经典海龟策略完整规则

### 1. 市场与品种选择

- 只交易**流动性充足**的市场(原版:国债、外汇、原油、黄金、咖啡等期货)。
- 多品种分散,品种间相关性越低越好。
- 不因为个人观点跳过任何信号——**所有信号必须执行**(海龟实验中亏损最多的学员就是挑单的)。

### 2. 核心变量 N(即 ATR)

N 是整个体系的地基,一切仓位、止损、加仓全部基于 N。

```
TR  = max(High - Low, |High - PrevClose|, |Low - PrevClose|)
N   = TR 的 20 日指数/威尔德平滑均值(即 ATR20)
```

- N 代表该品种"一天的正常波动幅度"。
- 每天开盘前用前一日数据更新 N。

### 3. 头寸单位(Unit)——波动率归一化仓位

海龟最核心的发明:**让每个品种"一天的波动"对账户的伤害相等**。

```
1 Unit 的合约数量 = (账户净值 × 1%) / (N × 每点价值)
```

含义:持有 1 Unit,当天该品种走出 1N 的波动,账户盈亏约 ±1%。

- 账户回撤时用**缩水后的净值**计算 Unit(亏 10% → 按 90% 资金算,天然减仓)。
- 原版更激进的规则:每亏损 10%,按亏损 20% 计算仓位(加速降杠杆)。

### 4. 入场规则(两套系统并行)

#### 系统一(S1):短线,20 日突破

- **做多**:价格突破最近 20 日最高价 → 买入 1 Unit。
- **做空**:价格跌破最近 20 日最低价 → 卖出 1 Unit。
- **过滤器**:如果上一次 S1 信号是**盈利的**,则跳过本次信号(赢利后休息,避免趋势末端追高);若跳过后价格走出 55 日突破,则按系统二强制入场,保证不错过大趋势。

#### 系统二(S2):长线,55 日突破

- **做多**:突破 55 日最高价 → 买入 1 Unit。
- **做空**:跌破 55 日最低价 → 卖出 1 Unit。
- 无过滤器,所有信号必须执行。

> 入场使用**突破即市价追入**(或突破价挂止损买单),不等回调——这一点与回调型策略本质不同。

### 5. 加仓(金字塔)规则

趋势验证一次,加码一次:

- 首仓成交后,价格每**顺势移动 0.5N**,加仓 1 Unit。
- 单品种上限 **4 Units**。
- 每次加仓后,**全部持仓的止损统一上移**到"最新一笔加仓价 - 2N"(做多)。

示例(做多,入场价 100,N = 2):

| 动作 | 触发价 | 持仓 | 统一止损价 |
|---|---|---|---|
| 首仓 | 100 | 1U | 96 |
| 加仓1 | 101 | 2U | 97 |
| 加仓2 | 102 | 3U | 98 |
| 加仓3 | 103 | 4U(满) | 99 |

### 6. 止损规则(生命线)

- **任何一笔头寸,止损距离 = 2N**,对应账户风险 = 2%(1 Unit × 2N × 1%/N)。
- 止损是**硬性的、入场瞬间就确定的**,不允许扛单、不允许移远。
- 满仓 4 Units 时,由于加仓后统一上移止损,整体最大风险约为账户的 5%(而非 8%)。

### 7. 离场(止盈)规则

离场同样是机械的反向突破,**没有固定盈利目标**:

- **S1 持仓**:多头跌破 **10 日最低价** / 空头突破 10 日最高价 → 全部平仓。
- **S2 持仓**:多头跌破 **20 日最低价** / 空头突破 20 日最高价 → 全部平仓。

> 这意味着必然回吐一段利润——海龟接受回吐,换取不错过任何大趋势的延伸段。

### 8. 总风险上限(分层限额)

| 层级 | 上限 |
|---|---|
| 单品种 | 4 Units |
| 高度相关品种组(如原油+燃油) | 6 Units |
| 松散相关品种组 | 10 Units |
| 单方向总仓位(全部多头或全部空头) | 12 Units |

### 9. 经典海龟的盈利结构

- 胜率通常只有 **35%~45%**,大部分交易小亏(震荡市假突破)。
- 盈利依赖每年少数几次大趋势的**长尾利润**(盈亏比 3~5 以上)。
- 系统靠**纪律 + 仓位控制**存活,而不是靠信号精度。

## 第二部分:高杠杆合约环境改造(加密货币永续合约)

### 0. 改造总纲:先想清楚杠杆到底是什么

**关键认知:在海龟体系里,杠杆不是风险开关,Unit 公式才是。**

经典海龟的 1 Unit 本身就常隐含 3~5 倍名义杠杆(期货保证金机制),但单笔风险始终锁死在 1%~2%。改造的原则:

> **杠杆倍数只决定"保证金占用效率"和"爆仓价距离",单笔亏损金额永远由 Unit 公式 + 2N 止损决定。**

高杠杆环境下真正新增的风险只有三个:**爆仓价先于止损价被触发、资金费率损耗、插针滑点**。改造就围绕这三点展开。

### 1. 参数体系改造(加密市场特性)

加密市场 24/7 交易、波动率是传统商品的 3~5 倍、趋势节奏更快,周期参数需整体压缩:

| 参数 | 经典版(日线) | 高杠杆合约版(4H 线) | 说明 |
|---|---|---|---|
| N 周期 | ATR20(日) | **ATR20(4H)** | 用 4H 作为主周期,日线太慢、1H 假突破太多 |
| S1 入场 | 20 日突破 | **20 根 4H 突破**(≈3.3 天) | 节奏对应压缩 |
| S2 入场 | 55 日突破 | **55 根 4H 突破**(≈9 天) | |
| S1 离场 | 10 日反向突破 | **10 根 4H 反向突破** | |
| S2 离场 | 20 日反向突破 | **20 根 4H 反向突破** | |
| 加仓间隔 | 0.5N | **0.5N(不变)** | |
| 止损距离 | 2N | **2N(不变,但见 §3)** | |

> 也可用日线原参数做"慢海龟",4H 做"快海龟",两套并行分散节奏风险(对应原版 S1/S2 双系统思想)。

### 2. Unit 公式改造(高杠杆下的仓位计算)

**单笔风险从 1% 降到 0.5%**(理由:加密波动率高、插针滑点大、24 小时无法盯盘):

```
单笔风险额   R = 账户净值 × 0.5%
1 Unit 名义价值 = R / (2N / 入场价)          ← 用"2N止损打掉刚好亏R"反推
1 Unit 合约张数 = 1 Unit 名义价值 / (入场价 × 每张面值)
所需保证金     = 1 Unit 名义价值 / 杠杆倍数
```

**示例**:账户 10,000 USDT,BTC 价格 60,000,4H 的 N = 600(1%):

- R = 50 USDT
- 2N 止损幅度 = 1200/60000 = 2%
- 1 Unit 名义价值 = 50 / 2% = **2,500 USDT**(名义仓位仅为账户的 25%)
- 若开 10x 杠杆,占用保证金仅 250 USDT——**杠杆只是让保证金占用变小,亏损上限仍是 50 USDT**

**硬性检查(每次开仓前必须执行)**:

```
爆仓价距离 > 3N          ← 否则强制降低杠杆倍数或减少张数
名义总仓位 ≤ 账户净值 × 3   ← 全账户名义杠杆上限 3 倍(见 §5)
```

> **绝对禁止**反向使用杠杆:"我开了 20x 所以仓位可以是账户的 20 倍"——这是爆仓公式,不是海龟。

### 3. 止损改造(高杠杆下的三重防线)

高杠杆环境的止损必须防插针、防爆仓、防交易所宕机:

1. **第一防线:2N 条件止损单(交易所侧)**
   - 入场成交的**同一秒**在交易所挂出止损单(如 OKX 的止盈止损委托),而不是程序内存里的"逻辑止损"。程序崩溃、断网时交易所单仍然生效。
   - 触发价用**标记价格**而非最新成交价,防止插针误触发(方向性保护)与漏触发。

2. **第二防线:爆仓价缓冲**
   - 开仓前校验:爆仓价必须在止损价之外至少 1N。不满足 → 降杠杆(如 20x → 10x → 5x)直到满足。
   - 逐仓模式,**永远不用全仓**——单品种最坏情况只烧掉该仓位保证金。

3. **第三防线:账户级熔断**
   - 单日账户回撤 ≥ 5% → 当日停止一切新开仓。
   - 账户从高水位回撤 ≥ 15% → 所有 Unit 规模减半(在 0.5% 基础上再砍半),直到净值回到高水位的 95%。
   - 账户回撤 ≥ 25% → 全部平仓,停机复盘,人工决定是否重启。

### 4. 加仓改造(高杠杆下收紧金字塔)

经典 4 Units 满仓时总风险约 5%,高杠杆环境下滑点和插针会放大实际亏损,收紧为:

- 单品种上限 **3 Units**(而非 4)。
- 加仓间隔从 0.5N 放宽到 **1N**(减少趋势初期的假突破反复加仓)。
- 每次加仓后统一上移止损至"最新加仓价 - 2N"(不变)。
- **资金费率过滤**:若当前资金费率方向对持仓不利且 8 小时费率绝对值 > 0.05%,暂停加仓(仅持有已有仓位)。

满仓 3 Units 的最坏情况:约亏账户 **2%**(0.5% 风险基数 + 止损上移),完全可承受。

### 5. 总风险限额改造

| 层级 | 经典版 | 高杠杆合约版 |
|---|---|---|
| 单品种 | 4 U | **3 U** |
| 高相关组(BTC/ETH 及主流币视为同一组) | 6 U | **4 U** |
| 山寨币组 | — | **3 U**(山寨相关性极高,视为一个品种) |
| 单方向总计 | 12 U | **8 U** |
| 全账户名义杠杆 | — | **≤ 3 倍净值**(硬上限) |

> 加密市场的残酷现实:暴跌时所有币相关性趋近 1。品种分散在加密市场提供的保护远小于商品期货,所以总限额必须比经典版更紧。

### 6. 入场执行改造(针对合约微观结构)

- **突破确认**:用 **4H 收盘价突破** 而非盘中触及(经典海龟用盘中触及)。加密插针太多,盘中触及会产生大量假突破;代价是入场价略差,属于值得的交换。
- **下单方式**:收盘确认后,下**限价单追价**(限价 = 现价 + 0.05% 容忍度)或直接 IOC 市价单;小市值币种必须用限价,防止吃穿盘口。
- **S1 盈利过滤器保留**:上次 S1 盈利则跳过下次 S1 信号,55 根突破(S2)兜底——该规则在高波动市场同样有效,能避开趋势末端追高。
- **流动性门槛**:只交易 24h 成交额 > 1 亿 USDT、盘口 0.1% 深度 > 50 万 USDT 的永续合约。

### 7. 离场改造

- 反向突破离场规则不变(S1 用 10 根 4H、S2 用 20 根 4H),同样用**收盘确认**。
- **新增波动率熔断离场**:若单根 4H K 线振幅 > 4N(极端行情/黑天鹅),立即市价平掉全部该品种仓位,不等反向突破——高杠杆下不给极端行情第二根 K 线的机会。
- **新增资金费率离场**:持仓方向资金费率连续 3 个周期(24h)对己不利且累计 > 0.15%,且浮盈 < 1N,平仓(费率会持续侵蚀高杠杆仓位)。

### 8. 与经典版的核心差异汇总

| 维度 | 经典海龟 | 高杠杆合约版 | 改造原因 |
|---|---|---|---|
| 单笔风险 | 1%~2% | **0.5%** | 波动率高、插针滑点、24h 无人值守 |
| 周期 | 日线 | 4H | 加密趋势节奏快 |
| 突破判定 | 盘中触及 | 收盘确认 | 防插针假突破 |
| 单品种上限 | 4 U | 3 U | 收紧尾部风险 |
| 止损 | 电话下单 | 交易所侧条件单(标记价触发)+ 爆仓缓冲 ≥ 3N + 账户熔断 | 高杠杆容错为零 |
| 保证金模式 | — | 逐仓 | 隔离单品种爆仓 |
| 名义杠杆 | 隐含 3~5x | 保证金杠杆随意(10~20x),但名义总杠杆 ≤ 3x 净值 | 杠杆≠风险,Unit 公式才是 |
| 新增 | — | 资金费率过滤/离场、波动率熔断、流动性门槛 | 永续合约特有摩擦 |

### 9. 高杠杆版必须遵守的铁律(违反任何一条 = 不是海龟,是赌博)

1. 止损单与开仓单**同时**提交到交易所,永不裸奔。
2. 仓位大小只由 `0.5% ÷ 2N` 决定,**永远不由杠杆倍数决定**。
3. 亏损后按缩水净值算 Unit,**禁止**为"回本"放大仓位。
4. 所有信号无条件执行,不挑单、不预测、不因"感觉要反转"提前止盈。
5. 账户熔断触发后,冷静期内**任何理由都不重新开仓**。

## 附:与本项目现有策略的对照(可选参考)

| 维度 | 你的 Pro3 双周期策略 | 海龟(高杠杆版) |
|---|---|---|
| 入场逻辑 | 回调恢复(MACD 平滑翻转 + 限价回踩) | 突破追入(N 根 K 线新高/新低) |
| 趋势过滤 | 长周期 MACD 方向 | 无显式过滤,靠突破本身 + 2N 止损试错 |
| 止损 | 无硬止损,靠信号反转 | 入场即挂 2N 硬止损 |

| 加仓 | 无 | 顺势 1N 金字塔,上限 3U |

若要把海龟的风控嫁接到现有策略,优先级:**① 2N 交易所侧硬止损 → ② N 值归一化仓位 → ③ 账户级熔断**。你已有 ATR 计算(策略文件末尾的 `atr_value`),①② 均可直接落地。
