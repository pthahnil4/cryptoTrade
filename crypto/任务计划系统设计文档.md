# 任务计划系统 - 设计文档（长期主义版本 Longtermism v1.1）

> 版本说明：本版本为 **长期主义设计 v1.1**。取消强制每日时长与罚款机制，改为**灵活参与模式**——
> 核心指标从"每日达标小时数"转变为"**在场天数**"（有打卡记录的日期数）。
> 设计原则：**今天在场，比今天做多少更重要。**
> v1.1 增补：**历史最佳连续在场**（断档不归零）、**在场日历**（断档如实呈现）、
> **身份认同文案**（你是一个长期主义者）、**提前奖励改为 ×1**（不翻倍）、**结算后再循环引导**。

## 1. 概述

**任务计划系统**是一个集成在加密货币交易监控台中的**长期主义自我激励模块**，围绕两大终极目标，用"计划 → 任务卡 → 小时记录"的结构把大目标拆解为可执行、可记录、有奖励的任务卡，驱动自己**长期持续地在场**。

### 1.1 两大终极目标

| 轨道 | 总时长 | 拆解 | 终极目标 |
|------|--------|------|----------|
| 📚 学习 | 1000 小时 | 10 个 100 小时学习任务 | 彻底做出稳定运行的量化交易系统 |
| 💰 交易 | 1000 小时 | 10 轮 × 100 小时翻倍挑战 | 资金翻 10 番（1000 倍，达到 10 万 U） |

### 1.2 设计理念（长期主义）

- **知识平权时代**：可以疯狂吮吸知识、填充自己、让自己进化
- **对抗人生三大痛苦**：
  1. 自由问题 —— 一生穷困，时间被强制占用
  2. 眼界问题 —— 知道会涨，但是没钱买
  3. 成就问题 —— 巨大的成就和革命与我无关
- **长期主义核心**：
  - **低门槛启动**：想开始就开始，几分钟也算在场，没有任何心理负担
  - **坚持比强度更重要**：系统唯一关心的硬指标是"今天在场吗"，而不是"今天做了多少"
  - **不惧中断**：允许任意中断与回归，中断不罚款、不扣分、不重置
  - **任务完成即通关**：子目标完成即可提前通关领奖，无需硬耗 100 小时
  - **只报喜不施压**：界面永不显示"缺口/达标/罚款"类施压信息
  - **身份认同**：你是一个长期主义者——行为由身份驱动，而非压力驱动
  - **历史最佳**：断档不可怕，大字只显示历史最佳连续在场；断档如实呈现在场日历，随时可以续上

> 长期主义的敌人不是短期失败，而是"退出"。本系统的一切机制都在服务同一件事：**让你永不退出**。

## 2. 概念模型

```
计划（Plan）
├── 学习计划（1000h）     → 10 张学习任务卡
├── 交易计划（1000h）     → 10 张交易轮次卡
├── 在场统计（自动汇总）  → 累计在场天数 / 历史最佳连续在场 / 在场日历（取代旧版罚款）
├── 结算（Settlement）    → 通关后奖励核算（基础 + 提前，无扣款）
└── 统计看板              → 进度 / 在场天数 / 命中率 / 奖金

任务卡（Card）内包含：
├── 100 格打卡 slots[]       → 100 个格子，每格填 1 条时长记录（任意时长）
├── 目标拆解 milestones[]   → 子目标逐条勾选；全部完成 → 提前通关
├── 过程小记 notes[]        → 自由记录
└── 复盘总结 review         → 通关后填写
```

### 2.3 100 格打卡系统 (Slot)

每张任务卡内置 **100 个格子**，对应 100 个小时。每个格子是一条时长记录槽位，设计为"可视化在场记录"形式：

```json
{
  "slots": [
    {
      "slot_index": 0,           // 格子索引 0~99
      "filled": true,            // 是否已勾选
      "filled_at": "2026-08-07 09:00",  // 勾选时间（在场日期以此为准）
      "record": {
        // 学习卡
        "content": "学习OKX SDK高级订单",
        "duration_minutes": 45
      }
    },
    {
      "slot_index": 1,
      "filled": false,
      "filled_at": "",
      "record": null
    }
  ]
}
```

**交易卡 record 格式：**

```json
{
  "prediction": "涨",        // 涨 / 跌 / 横盘
  "actual": "涨",            // 可选，回填实际涨跌
  "hit": true,               // 回填后自动计算
  "duration_minutes": 30
}
```

> **设计原则**：slots 是时长统计与**在场统计的唯一数据源**。日汇总、轮次累计、在场天数全部由 slots 聚合。
> **在场判定**：当天存在任意 `filled=true` 的记录（`filled_at` 的日期部分）即记为"在场一天"，**时长多少不限**。

> **交互方式**：页面展示 10×10 的格子矩阵，✔=已勾选（绿色），□=未勾选（灰色）。点击格子 → 弹窗填写内容（时长最低 1 分钟）。勾选后格子变色，进度条同步更新。

### 2.4 预置生成规则

| 动作 | 规则 |
|------|------|
| 创建学习计划 | 自动生成 10 张学习任务卡（round=1~10），每张 slots 预置 100 个空格子 |
| 创建交易计划 | 自动生成 10 张交易轮次卡（round=1~10），每张 slots 预置 100 个空格子 |
| 手动创建 | 页面保留"+ 新学习任务"和"+ 新交易任务"按钮，手动创建的卡 round 从 11 开始 |
| 串行解锁 | 当前任务未通关时，后续任务卡不可勾选格子（但可查看） |

### 2.5 结算 (Settlement) —— 通关后生成

```json
{
  "base_reward": 2000,        // 基础奖金
  "total_hours_used": 90,     // 实际使用时长（小时）
  "early_hours": 10,          // 提前完成小时数
  "early_bonus": 200,         // 提前奖励 = 10h × 时薪 20 × 1（v1.1 不翻倍）
  "final_reward": 2200,       // 最终奖金（= 基础 + 提前，无扣款）
  "settled_at": "2026-08-14 18:00:00"
}
```

### 2.6 参与规则 (DailyRule) —— 长期主义模式

| 轨道 | 参与门槛 | 在场判定 | 强制要求 |
|------|---------|---------|---------|
| 学习 | 任意时长（最低记录 1 分钟） | 当天有打卡记录 = 在场 1 天 | **无** |
| 交易 | 任意时长（最低记录 1 分钟） | 当天有打卡记录 = 在场 1 天 | **无** |

```json
{
  "mode": "longtermism",
  "min_record_minutes": 1,
  "early_bonus_multiplier": 1,     // v1.1：提前奖励不翻倍（×1）
  "welcome_message": "今天也想开始了吗？随时欢迎 👋"
}
```

> 旧版"三档罚款规则"（≥10h 达标 / 6~10h ×2 / <6h ×4）**已废弃**，仅保留在历史数据中作参考，不再参与任何计算。

### 2.7 在场日历 (Presence Calendar) —— v1.1 新增

每计划自动生成**近 15 周**（105 天）的在场日历，每天一格：

```json
{
  "start_date": "2026-05-04",      // 起始日期（今天所在周的周一往前 14 周）
  "weeks": 15,
  "days": [
    { "date": "2026-05-04", "minutes": 45, "level": 2, "future": false }
  ]
}
```

- `minutes`：当天所有打卡的时长总和；`future`：未来日期（半透明展示）
- `level` 分级（GitHub 贡献图风格）：0 = 未在场，1 = 1~29 分钟，2 = 30~59，3 = 60~119，4 = 120+ 分钟
- 设计意图：**断档如实呈现，但绝不惩罚**——与"最佳连续在场"（只增不减）配合，数据诚实、情绪友好

## 3. 业务规则

### 3.1 学习轨道（1000 小时 → 量化交易系统）

1. 总目标 1000 小时，拆成 **10 个 100 小时**的学习任务，**串行推进**（完成上一个解锁下一个）
2. **无每日强制时长**：想学多少学多少，10 分钟也算在场
3. **中断自由**：中断不罚款、不扣分、不重置；**大字只显示历史最佳连续在场**（断档不归零），断档如实呈现在场日历
4. **自动通关**：累计学习 ≥ 100 小时
5. **提前通关**：子目标全部完成 → 任务完成即通关，无需硬耗 100 小时
6. **提前奖励**：`剩余小时 × 学习时薪 × 1`（v1.1 起不翻倍——提前通关本身就是奖励：时间自由）
7. **完成奖励**：默认 **2000 元**，可手动更改；下一个学习任务默认与上一个学习任务**最终奖励一致**（继承机制）

### 3.2 交易轨道（多轮翻倍 · 1000 小时 → 10 万 U）

#### 一、单轮通关标准与基础规则

| 规则 | 内容 |
|------|------|
| 时长要求 | 单轮累计 100 个交易小时（无每日强制，任意时长均可记录） |
| 通关要求 | 全程平均每小时盈利 1%，完成账户本金全额翻倍 |
| 基础奖励 | 第 1 轮 2000 元，第 N 轮固定为 2000×N 元，提前完成可获额外奖励 |
| 失败规则 | 结算时资金倍数 < 2，本轮任务失败，奖金为 0 |
| 奖励继承 | 奖励默认按 2000×N 等差生成；手动修改某轮后，下一轮默认 = 上一轮最终值 + 2000 |

#### 二、奖金核算规则（无罚款）

- 基础奖励：完成 100 小时或达成翻倍目标，全额发放对应轮次基础奖金
- 提前奖励：按本轮基础时薪的 **1 倍/小时** 计算（v1.1 起不再翻倍）
  - 核算公式：`基础时薪 = 本轮基础奖金 ÷ 100小时`；`单轮总奖金 = 基础奖金 + 提前总奖励`
  - 示例（基础奖金 8000 元）：基础时薪 80 元，每提前 1 小时额外奖励 80 元
- **无每日罚款**：不设每日达标线，任何一天都没有罚款扣减
- 兜底规则：仅翻倍目标未达成判定为 0 奖金，无其他倒扣机制

#### 三、多轮阶梯奖励规则（单轮通关解锁下一轮，轮次独立结算）

| 轮次 | 基础奖金 | 基础时薪 | 提前 1 小时奖励 |
|------|---------|---------|----------------|
| 第 1 轮 | 2000 元 | 20 元 | 20 元 |
| 第 2 轮 | 4000 元 | 40 元 | 40 元 |
| 第 3 轮 | 6000 元 | 60 元 | 60 元 |
| 第 N 轮 | 2000×N 元 | 20×N 元 | 20×N 元 |

- 整体奖励封顶：10 轮基础总奖励 **11 万元**，提前奖励上限 **11 万元**（v1.1 不翻倍），10 轮合计最高总奖励 **22 万元**

#### 四、奖金核算示例

| 场景 | 计算 | 结果 |
|------|------|------|
| 第 1 轮 90 小时完成（提前 10h） | 2000 + 10×20 | 2200 元 |
| 第 1 轮 50 小时完成（提前 50h） | 2000 + 50×20 | 3000 元 |
| 第 2 轮 80 小时完成（提前 20h） | 4000 + 20×40 | 4800 元 |
| 第 3 轮 70 小时完成（提前 30h） | 6000 + 30×60 | 7800 元 |

#### 五、通用执行规则

1. 轮次独立计时、独立判定，单轮失败不影响过往轮次已获奖励
2. 全程需稳定匀速盈利，禁止重仓赌单、短时套利爆赚等违规操作
3. 任务奖金无固定上限，最终金额由轮次基础奖金、提前完成时长决定

#### 六、本金复利与测算

- 每成功通关一轮，账户本金**全额复利翻倍**；10 轮通关后，本金放大至初始本金的 **1024 倍**
- 全程每小时稳定盈利 1%，收益持续复利滚动
- 10 轮全额达标，最高总奖金成本 **22 万元**（基础 11 万 + 提前奖励 11 万）
- **交易完成 10 次任务，奖励为 11 万 ~ 22 万**

## 5. 奖励核算引擎

### 5.1 交易轮次核算公式

```
基础时薪        = 基础奖金 ÷ 100                       // 第N轮 = 20×N 元
提前小时数      = max(0, 100 − 已填格子数)
提前奖励        = 提前小时数 × 基础时薪 × 1              // v1.1 不翻倍
最终奖金        = 基础奖金 + 提前奖励                   // 无罚款扣减

通关条件：资金倍数 ≥ 2（本金翻倍）
失败判定：资金倍数 < 2 → 最终奖金 = 0
```

### 5.2 学习任务核算公式

```
学习时薪   = 学习任务奖励 ÷ 100                        // 默认 2000 元 → 时薪 20 元
提前奖励   = (100 − 实际总时长) × 学习时薪 × 1          // v1.1 不翻倍；子目标全部完成后生效
最终奖金   = 基础奖励 + 提前奖励                       // 无罚款扣减

自动通关   = 累计学习时长 ≥ 100 小时
提前通关   = 子目标全部完成（无需硬耗 100 小时）
完成奖励   = 默认 2000 元（可手动修改，下一个任务继承上一个最终值）
```

### 5.3 在场统计公式

```
在场天数        = 有任意 filled 记录的日期数量（按日期去重）
最佳连续在场天数 = 历史最长的一段"连续在场"天数
                  // 断档不归零、不惩罚——大字只显示最佳，只增不减
在场日历        = 近 15 周每天在场分钟数，分 5 级着色（见 2.7）
                  // 断档如实呈现，随时可以续上
```

### 5.4 页面展示的实时指标

| 指标 | 计算方式 |
|------|---------|
| 轮次累计时长 | slots 中 filled=true 的格子数 |
| 在场天数 | 按 5.3 实时统计（取代旧版"每日达标状态"） |
| 最佳连续在场 | 历史最长连续在场段（v1.1：断档不归零） |
| 在场日历 | 近 15 周每日在场时长分级着色（v1.1） |
| 累计罚款/扣款 | **已移除**（无罚款机制） |
| 预计奖励 | 实时按公式估算（基础 + 提前，通关前） |
| 预测命中率 | 已回填记录中 hit=true 数 ÷ 已回填记录总数 |
| 已获总奖金 | Σ 各轮 settlement.final_reward |

### 6.4 100 格打卡交互

- **格子布局**：10×10 网格矩阵，每格显示序号 1~100
- **状态颜色**：
  - □ 灰色 = 未勾选
  - ✔ 绿色 = 已勾选并填写
  - 鼠标悬停显示内容摘要（学习内容/预测方向）
- **点击勾选**：
  1. 点击一个未勾选的格子
  2. 弹出填写弹窗
     - 学习卡：`学习内容`（必填）+ `学习时长（分钟）`（默认 60，**最低 1 分钟**）
     - 交易卡：`预测方向`（涨/跌/横盘，必选）+ `交易时长（分钟）`（默认 60，最低 1 分钟）
  3. 确认后格子变绿，进度条 +1，提示"欢迎回来，长期主义者 🌱"
- **回填实际**：已勾选的交易格子支持回填"实际涨跌"，自动计算命中

## 10. 已确认规则汇总（2026-08-07 长期主义 v1.1 确认）

| 项 | 规则 |
|----|------|
| 参与模式 | **长期主义**：无强制每日时长、无罚款；任意时长可打卡（最低 1 分钟） |
| 核心指标 | 在场天数（累计）+ **历史最佳连续在场天数**（v1.1：断档不归零）+ **在场日历**（断档如实呈现） |
| 身份认同 | 全系统身份化文案："你是一个长期主义者"（v1.1） |
| 学习通关 | 满 100 小时自动通关；**子目标全部完成可提前通关**（提前奖励 = 剩余小时 × 时薪 × 1，v1.1 不翻倍） |
| 学习奖励 | 默认 2000 元，可改；下一个任务继承上一个最终奖励 |
| 交易通关 | 资金倍数 ≥ 2（本金翻倍）；奖金 = 基础 + 提前，无扣款 |
| 交易奖励 | 第 N 轮 = 2000×N 元（等差）；10 轮基础 11 万 + 提前上限 11 万（v1.1 不翻倍），总计封顶 22 万 |
| 结算后再循环 | 结算弹窗自动引导：还有未结束的卡 → "去开始下一张"；没有 → "再开一卡"（v1.1 防动力断崖） |
| 交易盈利数据 | 一期手动记录每日盈利，二期自动拉取 OKX 账户判定翻倍 |
| 计划卡预置 | 创建计划时自动生成 10 张任务卡（round=1~10），每张预置 100 个空格子；手动创建的卡从 round=11 开始 |
| 任务顺序 | 学习/交易任务均串行：通关上一个解锁下一个 |
