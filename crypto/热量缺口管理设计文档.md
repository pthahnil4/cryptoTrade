# 热量缺口管理系统 - 设计文档

## 1. 概述

**热量缺口管理系统**是一个集成在加密货币交易监控台中的**健康管理辅助模块**，通过记录每日体重、三餐饮食摄入与运动步数，自动计算基础代谢、摄入缺口、运动消耗和热量缺口，帮助用户科学量化每日热量收支。

### 1.1 系统目标

- 自动化热量计算：录入基础数据后系统自动完成所有公式计算
- 食物热量库积累：每次录入的食物自动入库，越用越便捷
- 进度可视化：通过累积热量缺口反映减脂/增重进度
- 数据持久化：所有记录与食物库均以 JSON 文件持久存储

## 3. 计算公式

### 3.1 基础代谢（BMR）

```
bmr = (10 × morning_weight / 2) + (6.25 × height) - (5 × age) + 5
```

其中 `height`、`age` 取自配置参数。

### 3.2 摄入缺口

```
total_intake = breakfast_calories + lunch_calories + dinner_calories
intake_deficit = bmr - total_intake
```

### 3.3 运动消耗

```
exercise_calories = daily_steps × step_frequency × weight_factor / 1000
```

其中 `step_frequency`、`weight_factor` 取自配置参数。

### 3.4 热量缺口

```
calorie_deficit = intake_deficit + exercise_calories
```

### 3.5 累积热量缺口

```
累积热量缺口 = 历史总热量缺口 + 当前记录热量缺口
```

### 3.6 当前进度

```
current_progress = cumulative_deficit / target_deficit × 100%
```

### 3.7 平均值统计

```
平均热量缺口   = Σ 热量缺口 / 记录天数
平均摄入       = Σ 三餐总摄入 / 记录天数
平均摄入缺口   = Σ 摄入缺口 / 记录天数
平均步数       = Σ 当日步数 / 记录天数
平均运动消耗   = Σ 运动消耗 / 记录天数
```

## 5. 计算引擎

### 5.1 Calculator 类设计

```python
class CalorieCalculator:
    """热量缺口计算引擎"""

    def __init__(self, config):
        self.height = config.get('height', 175)
        self.age = config.get('age', 29)
        self.step_frequency = config.get('step_frequency', 0.7)
        self.weight_factor = config.get('weight_factor', 55)
        self.target_deficit = config.get('target_deficit', 100000)

    def calc_bmr(self, morning_weight):
        """计算基础代谢"""
        return (10 * morning_weight / 2) + (6.25 * self.height) - (5 * self.age) + 5

    def calc_intake_deficit(self, bmr, breakfast, lunch, dinner):
        """计算摄入缺口"""
        total_intake = (breakfast or 0) + (lunch or 0) + (dinner or 0)
        return bmr - total_intake

    def calc_exercise_calories(self, daily_steps):
        """计算运动消耗"""
        if not daily_steps:
            return 0
        return daily_steps * self.step_frequency * self.weight_factor / 1000

    def calc_calorie_deficit(self, intake_deficit, exercise_calories):
        """计算热量缺口"""
        return intake_deficit + exercise_calories

    def calc_dashboard(self, records):
        """计算统计看板数据"""
        ...
```

### 5.2 计算时序

```
用户提交表单
    ↓
解析字段（date, morning_weight, breakfast_calories, ...）
    ↓
calc_bmr(morning_weight)          → bmr
calc_intake_deficit(bmr, 三餐)     → intake_deficit
calc_exercise_calories(steps)     → exercise_calories
calc_calorie_deficit(前两步结果)   → calorie_deficit
计算累积缺口（历史总和 + 当前）    → cumulative_deficit
    ↓
保存记录到 records.json
    ↓
检查食物名称是否在 food_db 中
    ↓ 不在则自动新增
返回完整记录 + 统计看板
```

## 10. 边界情况与容错

| 场景 | 处理方式 |
|------|----------|
| 早上称重为空 | 不计算 BMR，相关缺口标记为 0 |
| 三餐热量为空 | 视为 0 处理 |
| 当日步数为空 | 运动消耗计算为 0 |
| 重复日期 | 同一天再次保存 = 更新记录，累积缺口重新计算 |
| 食物名称不存在 | 自动新增到食物热量库，分类设为"其他" |
| 食物名称不区分大小写 | 搜索和去重均不区分大小写 |
| 食物名称含逗号 | 多个食物用逗号分隔，每个单独处理 |
| 删除记录 | 删除后重新计算所有后续记录的累积缺口 |

## 12. 已确认规则汇总（2026-08-04 确认）

| 项 | 规则 |
|----|------|
| 基础代谢公式 | Mifflin-St Jeor（男性版）：(10×早重/2) + (6.25×身高) - (5×年龄) + 5 |
| 运动消耗公式 | 步数 × 0.7 × 55 / 1000 |
| 热量缺口 | 摄入缺口 + 运动消耗 |
| 食物入库 | 录入时食物名不在库中，自动新增 |
