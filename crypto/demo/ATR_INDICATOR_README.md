# ATR指标计算功能说明

## 概述
ATR（Average True Range，平均真实波幅）是由J. Welles Wilder开发的技术指标，用于衡量价格波动性。ATR不预测价格方向，而是衡量价格变动的幅度。

## 功能特点

### 1. ATR计算方法
- **True Range计算**：取以下三个值的最大值
  - 当前最高价 - 当前最低价
  - |当前最高价 - 前一收盘价|
  - |当前最低价 - 前一收盘价|

- **ATR计算**：使用14周期的威尔德平滑移动平均
  - 第一个ATR = 14个TR的简单平均
  - 后续ATR = (前ATR × 13 + 当前TR) ÷ 14

### 2. 输出数据
- `atr_value`: ATR绝对值（价格单位）
- `atr_percentage`: ATR相对百分比（ATR/当前价格×100%）
- `price_volatility`: 价格波动幅度（同atr_value）

### 3. 波动性评估标准
- **高波动**: ATR百分比 > 3.0%
- **中等波动**: 1.5% < ATR百分比 ≤ 3.0%
- **低波动**: ATR百分比 ≤ 1.5%

## 实际应用

### 1. 风险管理
- **止损设置**: 建议使用2倍ATR作为止损距离
- **止盈设置**: 建议使用3倍ATR作为止盈距离
- **仓位管理**: 高ATR时减少仓位，低ATR时可适当增加

### 2. 交易策略
- **突破确认**: ATR突然增大可能预示真正的突破
- **震荡识别**: ATR较低时市场可能处于震荡状态
- **趋势强度**: ATR上升通常表示趋势加强

### 3. 时间周期应用
- **短周期(5m, 15m)**: 适合日内交易，关注短期波动
- **中周期(1H, 4H)**: 适合波段交易，关注中期趋势
- **长周期(1D, 1W)**: 适合长线投资，关注主要趋势

## 注意事项

1. **数据要求**: ATR计算需要至少15个周期的数据
2. **滞后性**: ATR是基于历史数据的指标，存在滞后性
3. **市场环境**: 不同市场环境下ATR的参考意义不同
4. **结合使用**: 建议与其他技术指标结合使用

## 技术参数

- **ATR周期**: 14（标准设置）
- **计算方法**: 威尔德平滑移动平均
- **精度**: 保留4位小数
- **百分比精度**: 保留2位小数
