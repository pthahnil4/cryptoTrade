# 任务计划功能模块说明（长期主义版本 Longtermism v1.1）

## 1. 模块简介

**任务计划**是监控台中的长期主义自我激励模块：把"做出稳定运行的量化交易系统"和"资金翻 10 番"两大终极目标，拆解为可执行、可记录、有奖励的任务卡，用"**今天在场**"驱动自己长期持续地进步。

> 🌱 **核心理念：今天在场，比今天做多少更重要。**

### 1.1 双轨道结构

```
┌─────────────────────────────────────────────┐
│            🌱 任务计划（长期主义系统）         │
├──────────────────────┬──────────────────────┤
│   📚 学习轨道         │   💰 交易轨道         │
│   1000 小时           │   1000 小时           │
│   = 10 个学习任务     │   = 10 轮翻倍挑战     │
│   每个 100 小时       │   每轮 100 小时       │
│   目标：量化交易系统  │   目标：10 番=1000倍  │
│                      │   （10 万 U）         │
└──────────────────────┴──────────────────────┘
```

### 1.2 设计理念（长期主义）

- **低门槛启动**：想开始就开始，任何时候都欢迎，几分钟也算在场
- **坚持比强度更重要**：核心指标是"在场天数"，不是"每日时长"
- **不惧中断**：允许任意中断与回归，中断不罚款、不扣分，回来永远被欢迎
- **任务完成即通关**：子目标完成即可提前通关领奖，无需硬耗 100 小时
- **只报喜不施压**：系统永不显示"缺口/达标/罚款"——那些只会带来心理负担
- **身份认同**：你是一个长期主义者——行为由身份驱动，而非压力驱动
- **历史最佳（v1.1）**：断档不可怕，大字只显示历史最佳连续在场；断档如实呈现在场日历，随时可以续上

> 长期主义的敌人不是短期失败，而是"退出"。本系统的一切设计都在服务同一件事：**让你永不退出**。

## 2. 功能总览

| 功能 | 说明 |
|------|------|
| 计划管理 | 创建/删除计划，内置"1000小时学习"与"1000小时翻倍交易"两个模板 |
| 任务卡管理 | 计划下自动生成 10 张任务卡（round=1~10），每张卡内置 100 个格子；支持手动创建更多卡（round 从 11 开始） |
| 100 格打卡 | 每张卡 100 个格子对应 100 小时，完成 1 小时勾选 1 格，弹窗填写内容；**几分钟也算在场** |
| 目标拆解 | 每张卡可拆解子目标，逐条勾选，进度 = x/y；**子目标全部完成即可提前通关** |
| 小时记录 | 学习卡格子：填"学习内容 + 学习时长"；交易卡格子：填"预测涨跌 + 交易时长" |
| 在场统计 | 自动汇总"在场天数"（有打卡记录的日期数）与"历史最佳连续在场天数"；**在场日历**（近 15 周）如实呈现每天在场情况，替代旧版每日达标判定 |
| 预测回填 | 交易记录可回填实际涨跌，自动计算命中率 |
| 过程小记 | 自由记录心得、发现、踩坑 |
| 复盘总结 | 每张卡通关后填写复盘 |
| 奖励核算 | 通关后自动结算：基础奖金 + 提前奖励（**无罚款扣减**） |
| 统计看板 | 总进度、已通关轮次、已获奖金、命中率、累计在场天数、在场日历 |

## 3. 学习任务规则

### 3.1 总目标与拆解

- **总目标**：学习 1000 小时，彻底做出**稳定运行的量化交易系统**
- **拆解**：1000 小时 = **10 个 100 小时**的学习任务
- **节奏不设限**：不设每日强制时长，想学多少学多少；10 小时也可以，10 分钟也可以

### 3.2 参与规则（长期主义版）

| 规则 | 内容 |
|------|------|
| 参与门槛 | **任意时长均可打卡**（最低记录 1 分钟）——只要来了，就是胜利 |
| 在场判定 | 当天有任意打卡记录 → 记为"在场 1 天" |
| 中断处理 | 中断不罚款、不扣分、不重置；**大字只显示历史最佳连续在场**，断档如实呈现在场日历，随时可以续上 |
| 强制要求 | **无**——没有每日达标线、没有严重线、没有罚款 |

### 3.3 任务完成

- **自动通关**：累计学习时长达到 **100 小时** → 该任务完成
- **提前通关**：**子目标全部完成** → 任务完成即通关，无需硬耗 100 小时
- **提前奖励**：提前完成按 `剩余小时 × 时薪 × 1` 计算额外奖励（v1.1 起不再翻倍——**提前通关本身就是奖励**：省下的时间比翻倍奖金更值钱）
- **完成奖励**：默认 **2000 元**，可手动更改
- **奖励继承机制**：下一个学习任务默认与上一个学习任务最终奖励一致

## 4. 交易任务规则（多轮翻倍激励方案）

### 4.1 单轮通关标准与基础规则

1. **时长要求**：单轮累计 100 个交易小时（无每日强制，任意时长均可记录）
2. **通关要求**：全程平均每小时盈利 1%，完成账户本金全额翻倍
3. **基础奖励**：第 1 轮 2000 元，第 N 轮固定为 2000×N 元，提前完成可获额外奖励
4. **失败规则**：结算时资金倍数 < 2 判定本轮失败，奖金为 0

### 4.2 奖金核算规则（无罚款）

1. **基础奖励**：完成 100 小时或达成翻倍目标，全额发放对应轮次基础奖金
2. **提前奖励**：按本轮基础时薪的 1 倍/小时计算（v1.1 起不再翻倍，提前通关本身就是奖励）
   - 核算公式：`基础时薪 = 本轮基础奖金 ÷ 100 小时`
   - `单轮总奖金 = 基础奖金 + 提前总奖励`
   - 示例（基础奖金 8000 元）：基础时薪 80 元，每提前 1 小时额外奖励 80 元
3. **无罚款**：不设每日达标线，任何一天都没有罚款扣减
4. **兜底规则**：仅翻倍目标未达成判定为 0 奖金，无其他倒扣机制

### 4.3 多轮阶梯奖励规则

单轮通关解锁下一轮，轮次独立结算：

| 轮次 | 基础奖金 | 基础时薪 | 提前 1 小时奖 | 100小时按时完成 |
|------|---------|---------|--------------|----------------|
| 第 1 轮 | 2000 元 | 20 元 | 20 元 | 2000 元 |
| 第 2 轮 | 4000 元 | 40 元 | 40 元 | 4000 元 |
| 第 3 轮 | 6000 元 | 60 元 | 60 元 | 6000 元 |
| 第 N 轮 | 2000×N 元 | 20×N 元 | 20×N 元 | 2000×N 元 |

- 整体奖励封顶：10 轮基础总奖励 **11 万元**
- 提前奖励上限 **11 万元**（v1.1 不翻倍）
- **10 轮合计最高总奖励 22 万元**
- 交易完成 10 次任务，奖励为 **11 万 ~ 22 万**
- **奖励继承机制**：奖励默认按 2000×N 等差生成；手动修改某轮后，下一轮默认 = 上一轮最终值 + 2000

### 4.4 奖金核算示例

| 场景 | 计算过程 | 结果 |
|------|---------|------|
| 第 1 轮 90 小时完成（提前 10h） | 2000 + 10 × 20 | **2200 元** |
| 第 1 轮 50 小时完成（提前 50h） | 2000 + 50 × 20 | **3000 元** |
| 第 2 轮 80 小时完成（提前 20h） | 4000 + 20 × 40 | **4800 元** |
| 第 3 轮 70 小时完成（提前 30h） | 6000 + 30 × 60 | **7800 元** |

### 4.5 通用执行规则

1. 轮次独立计时、独立判定，**单轮失败不影响过往轮次已获奖励**
2. 全程需**稳定匀速盈利**，禁止重仓赌单、短时套利爆赚等违规操作
3. 任务奖金无固定上限，最终金额由轮次基础奖金、提前完成时长决定

### 4.6 本金复利与测算

- 每成功通关一轮，账户本金**全额复利翻倍**
- **10 轮通关后，本金放大至初始本金的 1024 倍**
- 全程每小时稳定盈利 1%，收益持续复利滚动
- 10 轮全额达标，最高总奖金成本 22 万元（基础 11 万 + 提前奖励 11 万）

## 5. 页面与操作指南

### 5.1 入口

- 顶部导航栏点击 **📋 任务计划**，进入 `/plan` 页面

### 5.2 总览看板

- 页面顶部展示长期主义欢迎横幅与统计指标：
  - 📚 学习：总进度、任务完成 x/10、学习累计在场天数
  - 💰 交易：总进度、已通关 x/10 轮、交易累计在场天数
  - 🌱 累计在场天数、🔥 最佳连续在场（历史）、已结算奖励、预测命中率

### 5.3 今日在场面板

- **只报喜不施压**：显示"✅ 今天也在场 · 欢迎回来，长期主义者 🌱"或"🌙 今天还没开始，随时欢迎 👋"
- 今日学习/交易时长、各轨道累计在场天数
- **🌱 在场日历（v1.1）**：GitHub 贡献图风格，展示近 15 周每天的在场时长（颜色由浅到深 = 时长由少到多）——断档如实呈现，悬停可看具体日期与分钟数
- 永不显示"缺口、达标线、罚款"等施压信息

### 5.4 计划详情（任务卡列表）

- **任务卡列表**：10 张卡展示进度条（累计时长/100h）、状态标签、在场天数、预计奖励

### 5.5 任务卡详情弹窗

| Tab | 操作 |
|-----|------|
| 📋 概览 | 查看目标、奖励、起止时间、状态；切换状态（开始/完成/放弃）；维护子目标 |
| 🕐 100 格打卡 | 10×10 格子矩阵，✔ 已勾选 □ 未勾选，点击格子填写内容；**任意时长均可打卡** |
| 📝 过程小记 | 追加小记 |
| 💰 结算 | 查看：基础奖金、提前奖励、在场天数、最终奖金明细；**结算后自动引导**：还有未结束的卡 → "去开始下一张"；没有 → "再开一卡"（防止完成后的动力断崖） |

### 5.6 100 格打卡

- 每张任务卡是一个 **10×10 格子矩阵**，共 100 格，对应 100 小时
- 灰色 □ = 未勾选，绿色 ✔ = 已勾选
- **点击格子 → 弹出填写弹窗**：
  - 学习卡：填学习内容 + 学习时长（分钟，默认 60，**1 分钟起**）
  - 交易卡：选预测方向（涨/跌/横盘）+ 交易时长（分钟，默认 60）
- 已勾选的交易格子可回填"实际涨跌"，自动计算命中率
- 悬停格子显示内容摘要

### 5.7 任务创建机制

- **预置生成**：创建学习/交易计划时自动生成 10 张任务卡（round=1~10），每张卡预置 100 个空格子
- **手动创建**：页面保留"+ 新学习任务"和"+ 新交易任务"按钮，手动创建的卡 round 从 11 开始
- **串行解锁**：当前任务未通关时，后续任务卡不可勾选格子（但可查看）

### 5.8 每日使用流程（推荐）

1. 任何时候想开始 → 打开任务计划 → 点击格子开始，随时欢迎
2. 学到 1 分钟还是 3 小时都可以，勾选格子并填写内容
3. 收盘后回填各格子的"实际涨跌"，查看命中率
4. 不设任何每日目标——今天没来也没关系，明天随时回来
5. 100 格全部勾选 → 自动通关结算；**子目标全部完成 → 可提前通关**，领取奖励 → 结算弹窗自动引导"去开始下一张"或"再开一卡"

## 6. 长期主义原则（取代旧版三档罚款规则）

| 旧版规则（已废弃） | 长期主义版 |
|-------------------|-----------|
| 每日达标线 10 小时 | **无强制时长**，任意时长均可打卡 |
| 严重线 6 小时 | **无严重线**，中断不惩罚 |
| 缺口 × 时薪 × 2/4 罚款 | **无罚款**，奖励只增不减 |
| 每日结算判定 | **在场统计**：累计在场天数 + 历史最佳连续在场天数 + 在场日历 |
| 100 小时硬性完成 | **任务完成即通关**（子目标全部完成可提前通关） |

> 长期主义不惩罚短暂的离开，只奖励最终留下的人。

## 7. 核算公式速查

### 7.1 交易轮次

```
基础时薪      = 基础奖金 ÷ 100                       // 第N轮 = 20×N 元
提前奖励      = (100 − 实际总时长) × 基础时薪 × 1      // v1.1 不翻倍
最终奖金      = 基础奖金 + 提前奖励                   // 无罚款扣减

通关：资金倍数 ≥ 2（本金翻倍）
失败：资金倍数 < 2 → 奖金 0
```

### 7.2 学习任务

```
学习时薪   = 学习任务奖励 ÷ 100                        // 默认 2000 元 → 时薪 20 元
提前奖励   = (100 − 实际总时长) × 学习时薪 × 1          // v1.1 不翻倍；子目标全部完成后生效
最终奖金   = 基础奖励 + 提前奖励                       // 无罚款扣减

自动通关：累计学习 ≥ 100 小时
提前通关：子目标全部完成（无需硬耗 100 小时）
```

### 7.3 在场统计指标

| 指标 | 公式 |
|------|------|
| 在场天数 | 有任意打卡记录的日期数量（按日期去重） |
| 最佳连续在场天数 | 历史最长的一段"连续在场"天数（断档不归零，只增不减） |
| 在场日历 | 近 15 周每天在场分钟数，按 0/1-29/30-59/60-119/120+ 分钟分 5 级着色 |
| 预测命中率 | 命中数 ÷ 已回填记录数 |
| 累计已获奖励 | Σ 各轮结算最终奖金 |
| 总学习时长 | Σ 学习卡 slots 中 filled 格子数 |
| 总交易时长 | Σ 交易卡 slots 中 filled 格子数 |
