# 定时任务系统精简说明 — 交易核心机制

---

## 一、开仓条件与操作流程

### 1.1 开仓判断逻辑

系统根据 **短周期（默认1H）** 和 **长周期（默认1D）** 的 Pro3+ 信号方向，将行情分为四种场景：

| 场景 | 短周期方向 | 长周期方向 | 交易动作 | 开仓量 |
|------|-----------|-----------|---------|-------|
| 场景1：双周期共振多头 | 多头 | 多头 | **平空 + 开多** | 目标仓位 = 配置值（如0.3张） |
| 场景2：短空长多（冲突） | 空头 | 多头 | **平空 + 开多（减仓）** | 目标仓位 = 配置值 × 减仓比例（50%） |
| 场景3：短多长空（冲突） | 多头 | 空头 | **平多 + 开空（减仓）** | 目标仓位 = 配置值 × 减仓比例（50%） |
| 场景4：双周期共振空头 | 空头 | 空头 | **平多 + 开空** | 目标仓位 = 配置值（如0.3张） |

> **方向判定规则**：MACD柱状线 > 0 且 EMA > DMD → 多头；MACD柱状线 < 0 且 EMA < DMD → 空头；否则 → 观望。

### 1.2 开仓前的安全检查（全部通过才会执行）

```
✅ 无同方向活跃委托（防止重复下单）
✅ 无同方向挂单（已有挂单则跳过）
✅ 当前无同方向持仓 或 持仓 < 目标仓位（需要补仓）
✅ 持仓未达上限（单币种100张，总计500张）
✅ 账户余额充足
✅ 非强制平仓模式
✅ 无缓存的反向信号（防止信号抖动）
```

### 1.3 底仓管理

底仓是系统始终维持的最小持仓，**即使没有明确信号也不会平掉**。

| 操作 | 触发条件 | 执行方式 |
|------|---------|---------|
| **补底仓** | 当前持仓 < 底仓目标量 | TWAP 分3批开仓到目标仓位 |
| **减至底仓** | 反向信号出现，但系统选择不完全平仓 | TWAP 分3批减仓到底仓量 |
| **底仓补单** | 底仓挂单超时（配置时间）未成交 | 撤销旧单 → 市价立即成交 → 重新挂波动仓 |

### 1.4 BOLL 波动仓管理

在底仓之上，系统利用 **5分钟 BOLL 指标** 进行高抛低吸：

| 操作 | 触发条件 | 挂单价格 |
|------|---------|---------|
| **波动仓挂买单** | 当前持仓 ≤ 底仓目标量 | BOLL 下轨价格 |
| **波动仓挂卖单** | 当前持仓 > 底仓目标量 且 有底仓持仓 | BOLL 上轨价格 |
| **挂单维护** | 每10个周期检查一次 | 新价格与旧价格偏差 > 0.2% → 撤旧挂新 |

## 二、平仓条件与操作流程

### 2.1 信号反转平仓

| 触发条件 | 执行动作 |
|---------|---------|
| 场景1→场景3/4（短周期转空） | **平多仓**：TWAP 分3批减仓 → 减到0或底仓 |
| 场景4→场景1/2（短周期转多） | **平空仓**：TWAP 分3批减仓 → 减到0或底仓 |
| 反向信号确认 + 反向持仓达到目标 | 清除旧方向的缓存信号 |

### 2.2 止盈平仓

| 类型 | 触发条件 | 执行方式 |
|------|---------|---------|
| **移动止盈** | 持仓盈利达到阈值 | 以对手价5档挂限价单，持续跟踪价格移动 |
| **分批止盈** | 盈利达到 N 倍 ATR | 按阶梯比例减仓（同向：2/4/6 ATR，反向：1/2/3 ATR） |

### 2.3 强制平仓

| 触发条件 | 执行动作 |
|---------|---------|
| 人工配置 `manual_close_all = true` | 撤销所有活跃委托 → 市价全平 → 标记强制平仓模式 |
| 人工配置 `manual_close_long = true` | 平多仓 + 清除多头信号缓存 |
| 人工配置 `manual_close_short = true` | 平空仓 + 清除空头信号缓存 |

### 2.4 自动清理错误持仓

| 场景 | 自动处理 |
|------|---------|
| 持仓方向与信号方向相反（残留反向仓位） | 市价全平反向持仓 |
| 逐仓模式下仓位错误（多空都有 / 超出目标） | 市价全平 → 重新按信号开仓 |

## 三、交易通知触发条件

### 3.1 触发通知的三种事件

| 事件类型 | 触发时机 | 通知内容 |
|---------|---------|---------|
| **交易完成通知** | 开仓/平仓订单成功执行后 | 币种、方向、数量、价格、持仓变化 |
| **反转预警通知** | 短周期出现反向信号（尚未确认） | 当前趋势可能反转的预警 |
| **反转确认通知** | 双周期同时确认反转信号 | 趋势已确认反转，附带执行的动作 |

### 3.2 通知冷却标识

每种事件对每个币种有独立的冷却标识：

```
交易完成:   {symbol}_trade           例：NEAR-USDT-SWAP_trade
反转预警:   {symbol}_reversal_warning  例：NEAR-USDT-SWAP_reversal_warning
反转确认:   {symbol}_reversal_confirmed 例：NEAR-USDT-SWAP_reversal_confirmed
```

## 四、通知冷却时间机制

```
┌─────────────────────────────────────────────────────────────────┐
│                    通知发送流程                                  │
│                                                                 │
│  事件发生 ──→ 检查冷却标识 ──→ 是否在30分钟冷却期内？            │
│                                    │                            │
│                        ┌───────────┴───────────┐                │
│                        ↓                       ↓                │
│                    在冷却期内               不在冷却期            │
│                    → 跳过发送               → 发送邮件            │
│                                             → 记录冷却标识       │
│                                             → 设置30分钟过期     │
│                                                                 │
│  发送失败处理：                                                  │
│  → 最多重试 3 次，每次间隔 5 秒                                  │
│  → 3 次全部失败 → 记录失败日志，不影响主流程                      │
│                                                                 │
│  设计目的：                                                      │
│  → 5分钟级的策略可能每60秒执行一次                               │
│  → 无冷却期会导致同一信号重复发送大量邮件                         │
│  → 30分钟冷却期确保每个事件在半小时内最多通知一次                  │
└─────────────────────────────────────────────────────────────────┘
```

## 五、交易执行的委托类型

### 5.1 五种委托类型对比

| 委托类型 | 适用场景 | 执行方式 | 超时/降级 |
|---------|---------|---------|----------|
| **统一交易** | 通用入口 | 自动选择 TWAP 或 追逐限价 | — |
| **TWAP 时间加权** | 底仓补仓、信号不确定时开仓 | 分3批执行，间隔 = 总时长/3 | 失败 → 降级为普通限价单 |
| **追逐限价** | 信号确认时快速开仓/平仓 | 快速下单 + 自动追价 | 超时300秒 → 取消重试 |
| **普通限价单** | BOLL 波动仓挂单 | 以指定价格挂单 | 超时未成交 → 撤单重挂 |
| **移动止盈** | 止盈跟踪 | 以对手价5档挂单，持续移单 | 价格偏离 → 撤单重挂 |

### 5.2 信号类型决定委托方式

| 信号类型 | 条件 | 委托方式 |
|---------|------|---------|
| **UNCERTAIN（不确定）** | 短周期信号刚出现，长周期未确认 | TWAP 分批缓慢建仓 |
| **CONFIRMED（确认）** | 双周期方向一致 | 追逐限价委托快速建仓 |
| **DISAPPEARED（消失）** | 信号被缓存但超时未重现 | 撤销对应委托 |

### 5.3 各周期的执行参数

| 周期 | 执行间隔 | TWAP总时长 | 同向仓位比例 | 反向仓位比例 | 止盈（同/反ATR） |
|------|---------|-----------|------------|------------|----------------|
| **1H** | 60秒 | 50分钟 | 100% | 100% | 2/4/6 vs 1/2/3 |
| **15m** | 180秒 | 10分钟 | 50% | 50% | 1.5/3/4.5 vs 0.75/1.5/2.25 |
| **5m** | 60秒 | 5分钟 | 25% | 25% | 1/2/3 vs 0.5/1/1.5 |

### 5.4 防重复下单机制

```
每次交易前生成唯一签名：
  签名 = MD5(symbol + side + action + order_type)

  例：MD5("NEAR-USDT-SWAP" + "buy" + "open_long" + "twap")
      → "a3f2b8c1d4e5..."

执行流程：
  1. 检查签名是否已存在于 trade_state.json
  2. 已存在 → 跳过，防止重复下单
  3. 不存在 → 执行交易 → 写入签名
  4. 交易完成后删除签名，允许下次操作
```

## 六、完整交易决策流程图

```
每60-180秒执行一次（取决于周期）
         │
         ↓
   ┌─ 获取双周期信号 ─┐
   │   短周期(1H)     │
   │   长周期(1D)     │
   └────────┬─────────┘
            ↓
   ┌─ 人工干预检查 ─────────────────────────────────┐
   │  有人工方向配置？→ 覆盖信号方向                  │
   │  有强制平仓指令？→ 全平后退出                    │
   └────────┬───────────────────────────────────────┘
            ↓
   ┌─ 判断场景 ─────────────────────────────────────┐
   │  双多 → 场景1（全额开多）                       │
   │  短空长多 → 场景2（半额开多）                   │
   │  短多长空 → 场景3（半额开空）                   │
   │  双空 → 场景4（全额开空）                       │
   └────────┬───────────────────────────────────────┘
            ↓
   ┌─ 底仓检查 ─────────────────────────────────────┐
   │  持仓 < 底仓量？→ TWAP补仓到目标                │
   │  底仓挂单超时？→ 市价补单 + 重挂波动仓          │
   └────────┬───────────────────────────────────────┘
            ↓
   ┌─ 开仓/平仓决策 ────────────────────────────────┐
   │  需要平多？→ TWAP减多仓                         │
   │  需要开多？→ UNCERTAIN:TWAP / CONFIRMED:追逐限价│
   │  需要平空？→ TWAP减空仓                         │
   │  需要开空？→ UNCERTAIN:TWAP / CONFIRMED:追逐限价│
   └────────┬───────────────────────────────────────┘
            ↓
   ┌─ BOLL波动仓 ───────────────────────────────────┐
   │  持仓 ≤ 底仓 → 下轨挂买单                      │
   │  持仓 > 底仓 → 上轨挂卖单                      │
   │  价格偏差 > 0.2% → 撤旧挂新                    │
   └────────┬───────────────────────────────────────┘
            ↓
   ┌─ 后置检查 ─────────────────────────────────────┐
   │  信号消失？→ 撤销委托                           │
   │  信号反转？→ 反转预警通知（冷却30分钟）          │
   │  交易完成？→ 交易通知（冷却30分钟）              │
   │  盈利达标？→ 移动止盈跟踪                       │
   └────────────────────────────────────────────────┘
```
